How to use Analytikul

Short, practical guides for every part of the workspace. New features are documented here as they ship.

Getting started

Signing in and the workspace layout

Open the app from Chat or visit /chat. The left sidebar is your home base:

  • New chat — start a conversation
  • Search — find any past message
  • Notes — your notes workspace
  • Workspace — Models, Agents, Prompts, Skills, Org Memory, API Keys

Your account menu (bottom-left) holds settings and sign-out.

Starting your first conversation
  1. Click New chat.
  2. Pick a model from the selector at the top.
  3. Type your message and press Enter.

Chat & the Controls panel

Switching models

Use the model selector in the chat header to change models per conversation. You can keep different conversations on different models.

Using the Controls panel

Click the sliders icon in the chat header to open Controls — a right-side drawer with three sections:

  • System Prompt — set instructions for this conversation.
  • Advanced Params — every model parameter (temperature, top-p, max tokens, stop sequences, penalties, mirostat, and Ollama-specific tuning). Each shows Default until you override it.
  • Add Custom Parameter — pass any extra key/value the model supports.

A parameter only changes output if the active model's backend reads it — the Ollama-prefixed rows apply to Ollama-served models.

Saving a preset

Use the presets menu in the chat header to save the current model + parameters as a reusable preset, then apply it to future chats.

Building models

What is a "model" in Analytikul?

A model is a saved configuration on top of a base model — a system prompt, parameters, tools and capabilities bound together so you can reuse a specialist anywhere. Find them under Workspace → Models.

Creating a model
  1. Go to Workspace → Models and click New Model.
  2. Give it a name, description and instructions (system prompt).
  3. Pick a provider and base model.
  4. Enable capabilities — Code Interpreter, Web Search, File Search, File Context, Artifacts — and configure each as needed.
  5. Click Save. It appears as a card you can Edit, Duplicate or Delete.

Some capability uploads (knowledge files, code-environment files) become available after the model is saved the first time.

Agents & tool sets

Running an autonomous agent
  1. Open the Agent tab in the right-side panel.
  2. Expand Tools & model to choose which tool sets the agent may use, and optionally a provider/model.
  3. Describe the task and click Run agent.
  4. Watch the live trace, token use and cost as it works. Use Cancel any time.
Choosing tool sets

The agent can use 26 tool sets — web, search, vision, image/video generation, terminal, browser, files, memory, delegation, skills and more. Tick the ones you want; sensitive tools (messaging, computer use, home automation) are off by default.

Tool and model choices apply to a new agent conversation. Start a fresh run to change them.

Picking a provider & model for the agent

In Tools & model, choose a provider to load its models, or leave it on Default to use the workspace's configured agent model. For OpenRouter/Groq/Mistral, type the provider's model id directly.

Notes

Creating and formatting notes

Open Notes in the sidebar to create a note. The editor supports rich formatting, lists, headings and code, plus AI actions to summarize or rewrite. You can share a note with your organization.

Search

Finding past messages

Click Search in the sidebar, then type in the search box on the page. Results update as you type and cover every message across your conversations.

Org memory & API keys

Org memory

Open Workspace → Org Memory. Agents can save facts here to a shared memory, and you can view, add or remove them so your whole team benefits.

Bringing your own API keys

Open Workspace → API Keys to store provider keys (Anthropic, OpenAI, OpenRouter, Google, Groq, Mistral) in an encrypted vault. Agent and chat usage then runs on your own provider accounts.

Billing

How billing works

See Pricing for plans. Paid billing connects to Stripe soon; early accounts keep founding pricing. With your own API keys, model usage is billed by your provider at cost.

Cost tracking & budgets

The Costs tab in the right panel shows token and dollar usage. Admins can set budget caps that pause agent runs before they exceed a limit.
