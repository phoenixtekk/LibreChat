## Durable rebuild runbook (proven twice this session)

```bash
# on g3
cd ~/analytikul
git fetch origin && git checkout <HEAD> -- api client packages   # source only; leaves compose/.env
docker compose -p analytikul -f docker-compose.prod.yml build app   # ~35min, non-destructive
docker compose -p analytikul -f docker-compose.prod.yml up -d app    # recreate (brief downtime)
# re-apply what the image excludes (.dockerignore drops librechat.yaml):
BK=$(ls -t ~/librechat.yaml.live-backup-* | head -1); cat "$BK" | docker exec -i analytikul-app sh -c 'cat > /app/librechat.yaml'
docker network connect vllm_default analytikul-app
docker restart analytikul-app
```
The app build does a full in-image `npm run frontend`; root `package-lock.json`
rarely changes so `npm ci` stays clean. Tag the prior image as a rollback first.
