## Billing model — hybrid (resolved 2026-06-14)
- **Free tier:** platform-paid but **capped** — `CHECK_BALANCE=true` + `START_BALANCE` free grant
  (set by `gen-prod-env.sh`). No more uncapped chat.
- **Paid tiers:** subscription tops up LibreChat balance via the billing webhook
  (`PLAN_CREDIT_GRANT_PRO/TEAM` → `entitlements.grantPlanBalance`).
- **BYOK:** the agent path uses the per-user vault key when present (platform pays $0). Native-chat
  per-user BYOK is deferred (endpoint `user_provided` is all-or-nothing — see `docs/open-issues.md`).

## Tenant isolation (hardened 2026-06-14)
- Routes scope to `tenantId || userId` (`tenantOf`) — solo users are isolated; orgs share. No more
  `'default'` collapse. Note model has `applyTenantIsolation`. Backfill:
  `node scripts/analytikul-backfill-tenant.mjs`. `TENANT_ISOLATION_STRICT=true` available once
  tenant-context middleware is confirmed on all paths.

## Security hardening (2026-06-14 audit + fixes — branch `security/internal-svc-hardening`)
Internal services (billing 8013 / analytics 8011 / memory 8012 / gateway 8014 / hermes-adapter
8001) were published on `0.0.0.0` with **no auth of their own**. Fixed:
- **Compose:** all five now bind `127.0.0.1` only (host-loopback + intra-stack by service name).
- **Internal auth:** each service requires `x-internal-token` (== `INTERNAL_SERVICE_TOKEN`) on
  every non-`/health`, non-webhook route; the Node backend + gateway + adapter send it.
  **NEW REQUIRED ENV `INTERNAL_SERVICE_TOKEN`** (auto-generated by `scripts/gen-prod-env.sh`),
  enforced only when set — **must be set in prod on all services (compose wires it).**
- **Billing:** webhook idempotency (dedupe by provider event id → no replay/double-credit);
  credits booked from the *paid* amount, not client metadata; Polar fails closed on missing
  webhook secret; body-size cap; DB/Mongo creds fail-fast (no embedded-credential default).
- **Agent RCE floor:** the forbidden-toolset floor is now also enforced *inside* the runtime
  (`sessions.py`), non-overridable — not only in the Node route.
- **Gateway:** Telegram link codes are 24-byte (`token_urlsafe`), expire in 10 min, claimed
  atomically (no brute-force / replay / TOCTOU).
- **Budget:** platform-key runs fail **closed** when the budget service is unreachable (BYOK
  unaffected). Notes search `$regex` is escaped (no ReDoS).
- **Deploy step:** set `INTERNAL_SERVICE_TOKEN` in prod `.env`, redeploy the whole stack so every
  service shares the token. See `docs/open-issues.md`.
